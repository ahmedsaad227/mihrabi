بدون أي إطار عمل أو خادم. كل ما هو مذكور هنا مُختبر بالنقر الفعلي على الشاشة.

## ما لم يُبنَ (ومطلوب لبنائه)

- **تنبيه الصلاة على iOS وفي المتصفح**: على أندرويد صار مضموناً عبر الغلاف الأصلي (منبه دقيق + خدمة أذان). في المتصفح يبقى أفضل جهد عبر Periodic Background Sync، وعلى iOS يحتاج APNs وحساب آبل.
- **النشر في المتاجر**: يحتاج حساب Google Play (25$) وحساب Apple (99$/سنة) ومراجعة.
- **السحابة والحسابات والمزامنة**: يحتاج حسابك على Supabase (مجاني) — التصميم جاهز في `docs/backend.md`.
- **لوحة الإدارة**: مصمّمة، تحتاج نشر على حسابك.
- **المساعد الذكي «رفيق محرابي»**: يحتاج مفتاح API مدفوع + مصادر شرعية مراجعة.
- **الاشتراكات والدفع**: يحتاج بوابة دفع وحساب مطوّر.
- **مراجعة شرعية للنصوص**: الأذكار والتفسير والترجمات تحتاج مراجعة عالم قبل النشر العام.
- **استضافة رابط عام**: يحتاج حساب استضافة مجاني (Cloudflare Pages / GitHub Pages / Netlify).

كل هذا مذكور داخل التطبيق في شاشة «حالة المشروع» — ولا يوجد أي زر وهمي.

## البناء والاختبار (أمران فقط)

```bash
npm install                 # مرة واحدة (puppeteer-core للاختبارات)
npm test                    # يبني النسختين ويشغّل كل الاختبارات
```

`npm test` يبني ثم يشغّل، ويطبع عدد الفحوص الناجحة والفاشلة لكل مجموعة:

| الأمر | الناتج |
|---|---|
| `python3 build.py` | `dist/mihrabi.html` — ملف واحد يعمل بفتحه من القرص (بدون service worker، الصوت والخطوط مدمجة) |
| `python3 build.py --mode pages` | `dist-pages/` — مجلد مسطّح للنشر على https: `index.html` + `sw.js` + `manifest.webmanifest` + الأيقونات |
| `bash scripts/test-all.sh` | 12 + 21 + 28 فحصاً على نسخة الملفات المتعددة، و21 + 28 + 9 على نسخة النشر من مجلد فرعي، و168 مطابقة مواقيت مع واجهة aladhan |

الاختبارات تفتح Chrome حقيقياً وتنقر فعلياً: تشغيل الأذان والتحقق من الصوت، تبديل الترجمة، فتح التفسير، اللغات السبع،
حفظ نغمة الأذان، حالة التنبيه في الخلفية، والنسخة أحادية الملف من القرص. الاختبار يفشل إذا ظهر أي خطأ صفحة.

## النشر

- الويب: `https://ahmedsaad227.github.io/mihrabi/` (GitHub Pages من فرع `main`، جذر المستودع، مجلد `dist-pages`).
- التحديث: `python3 build.py --mode pages` ثم `python3 deploy/deploy-pages.py` بمفتاح GitHub في متغير `GH_TOKEN`.
- أندرويد: `android/mihrabi-0.3.apk` موقّع. ملفات الويب داخل التطبيق في `android/app/src/main/assets/www/` وتُزامَن من جذر المشروع.

## التشغيل

```bash
cd mihrabi
python3 -m http.server 8080
# افتح http://localhost:8080
```

> العمل بدون إنترنت (Service Worker) يحتاج `http://` أو `https://`، وليس `file://`.
> `dist/mihrabi.html` نسخة واحدة تعمل بالنقر المزدوج من `file://` وبداخلها كل شيء بما فيه الصوت (11.9 ميجا).

## أندرويد

```bash
# الملف الجاهز
android/mihrabi-0.3.apk

# إعادة البناء (JDK 17 + build-tools 34 + platform android-32)
cd android && ./build-apk.sh "$ANDROID_SDK/build-tools/34.0.0" "$ANDROID_SDK/platforms/android-32/android.jar"
```

مفتاح التوقيع في `android/keystore/` — **احتفظ به**، أندرويد يرفض تحديث تطبيق مثبّت بمفتاح مختلف.
التفاصيل في `android/README.md`.

```
dist/mihrabi.html     نسخة أحادية الملف
```
